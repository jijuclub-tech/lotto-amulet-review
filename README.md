# 천문·용맥 로또 부적 생성기 PWA

Claude 검수용 리포지토리입니다.

## 파일
- `lotto-amulet-mobile.html` : 메인 모바일 PWA (통계 필터 + 부적 카드 선택 + 형상 배열)

## 사용방법
1. HTML 파일을 모바일 브라우저에서 엽니다.
2. 종류 탭(천간, 지지, 별자리, 화투, 트럼프, 꿈 등) 선택
3. 카드 선택
4. 「나만의 천문 부적 발행하기」 버튼
5. 선택한 부적 모양으로 번호가 배열됩니다.

## 기능
- 첫 접속 100포인트, 1회 생성마다 -1
- 통계적 번호 필터 (홀짝, 연번, 구간, 최근 겹침 회피)
- 부적 형상 매칭 (북두칠성 등)
- 드림 카드 30개 이상 포함

Claude에게 이 파일을 검수해 달라고 전달해 주세요.
